Compute & Infrastructure

Terraform Linux Virtual Machine (Normal & for_each Modules)

Understand how to provision Azure Linux VMs individually and how to scale them with reusable modules using for_each.

1. Normal Standalone Linux VM

Provision the VNet, Subnet, Public IP, Network Interface (NIC), and azurerm_linux_virtual_machine with SSH keys and Ubuntu Jammy 22.04 LTS.

2. Module Architecture

Wrap the NIC, Public IP, and Linux VM into a modular package in modules/linux_vm/.

3. Multi-VM for_each Pattern

Loop over a map of VM configurations (such as web, api, worker) to build multi-tier infrastructures dynamically with minimal lines of code.

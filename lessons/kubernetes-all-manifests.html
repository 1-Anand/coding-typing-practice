Orchestration & YAML

All Essential Kubernetes Manifests

A complete inventory of production Kubernetes resource declarations with clean required spacing and standard YAML conventions.

Core Workloads & Config

  • Namespace: Project and team environment isolation (01-namespace.yaml).
  • ConfigMap: Environment variables and JSON application settings (02-configmap.yaml).
  • Secret: Sensitive database passwords and API tokens (03-secret.yaml).
  • Deployment: 3-replica production rolling update, securityContext, probes, and resource requests/limits (06-deployment.yaml).
  • Service: ClusterIP, NodePort, LoadBalancer, and Headless service patterns (07-service.yaml).
  • Ingress: NGINX ingress routing with TLS termination and path rewrites (08-ingress.yaml).

Storage, Autoscaling & Security

  • PV & PVC: PersistentVolumes and PersistentVolumeClaims for storage (04-pv.yaml, 05-pvc.yaml).
  • HPA: Dynamic horizontal autoscaling based on CPU and memory metrics (09-hpa.yaml).
  • StatefulSet: Stateful workloads with persistent volume templates (10-statefulset.yaml).
  • RBAC: ServiceAccount, Role, and RoleBinding for least-privilege access control (13-rbac.yaml).
  • NetworkPolicy: Fine-grained pod traffic ingress/egress restriction (14-networkpolicy.yaml).

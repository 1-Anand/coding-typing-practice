Containerization

Multi-Stage Dockerfiles (React, Java, .NET, Python)

Multi-stage Docker builds separate heavy build toolchains from minimal production runtimes, keeping final container images small, secure, and production-ready.

1. React Application

  • Build: node:18-alpine installs dependencies (npm install --legacy-peer-deps) and runs npm run build.
  • Run: nginx:alpine serves the static build output from /app/build on port 80.

2. Java / Spring Boot Application

  • Build: maven:3.9.6-eclipse-temurin-17 copies pom.xml, src/, and builds the jar package with mvn clean package -DskipTests.
  • Run: eclipse-temurin:17-jre-alpine runs the app.jar file with java -jar on port 8080.

3. .NET 8 Application

  • Build: mcr.microsoft.com/dotnet/sdk:8.0 restores *.csproj and publishes release binaries with dotnet publish.
  • Run: mcr.microsoft.com/dotnet/aspnet:8.0 runtime executes dotnet YourApp.dll on port 80.

4. Python Application

  • Build: python:3.11-slim pre-compiles wheel packages with pip wheel -r requirements.txt -w /wheels.
  • Run: Clean python:3.11-slim installs directly from /wheels and runs python app.py on port 5000.

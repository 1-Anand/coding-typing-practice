Containerization

Multi-Stage Dockerfiles (React, .NET, Python)

Multi-stage Docker builds separate build dependencies from production runtimes to drastically reduce image size and attack surface.

1. React Application

  • Build Stage: node:20-alpine runs npm ci and npm run build.
  • Run Stage: nginx:1.27-alpine serves the static HTML/JS/CSS assets with SPA client routing fallbacks.

2. .NET 8 Application

  • Build Stage: mcr.microsoft.com/dotnet/sdk:8.0 restores packages and publishes optimized binaries.
  • Run Stage: mcr.microsoft.com/dotnet/aspnet:8.0-alpine runs the app under non-root user app on port 8080.

3. Python Application

  • Build Stage: python:3.12-slim sets up a virtual environment and compiles package wheels.
  • Run Stage: Copies the clean /opt/venv without build tools or compilers, running as a non-root system user.

Containers & CLI

Docker Commands Reference & Real-World Uses

Master the complete set of everyday Docker commands used in production systems and DevOps workflows.

1. Image & Lifecycle

  • docker build -t app:1.0 . and docker build --no-cache
  • docker run -d --name web -p 8080:80 -v data:/app app:1.0
  • docker stop, docker restart, docker rm -f, docker rmi

2. Debugging & Live Troubleshooting

  • docker logs -f --tail 100 <container> - Stream live logs during triage
  • docker exec -it <container> sh - Access running container shell
  • docker stats --no-stream - Instant CPU/memory consumption check
  • docker inspect <container> - Query IP addresses, mounts, and health checks

3. Networks, Volumes & Cleanup

  • docker network create --driver bridge app-net
  • docker volume create app-data
  • docker system df & docker system prune -a --volumes -f
  • docker compose up -d & docker compose down -v

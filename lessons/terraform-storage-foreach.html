Infrastructure as Code

Terraform Storage Account (Normal & for_each Modules)

Learn the standard single-resource pattern and the modular for_each pattern for provisioning Azure Storage Accounts.

1. Normal Standalone Code

Direct resource definition of azurerm_storage_account with security defaults (TLS 1.2, HTTPS only, soft delete, and private containers).

2. Module Structure

Encapsulate the storage account and container inside modules/storage_account/ with main.tf, variables.tf, and outputs.tf.

3. The for_each Pattern

Call the module once using for_each = var.storage_accounts to declare multiple environments or storage tiers (logs, data, backups) cleanly without code duplication.
